# platen

In a printing press, the *platen* presses paper against inked type.

**Platen** presses structured data into documents.

See the [Platen user guide](https://cariad.github.io/platen) for usage and examples.

## Development

### Dependencies

- Python 3.14
- [uv](https://docs.astral.sh/uv/) for project management
- Optional: [just](https://github.com/casey/just) to run linting and testing tasks

### Setup

1. Set up the project environment:

   ```bash
   git clone git@github.com:cariad/platen.git
   cd platen
   uv sync
   ```

1. Optionally, if you have `just` installed, lint and test the project:

   ```bash
   just
   ```
